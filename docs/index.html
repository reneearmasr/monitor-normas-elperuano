Cómo funcionan

Una norma entra al resumen si su entidad, título o sumilla contiene alguno de estos términos (no distingue mayúsculas ni tildes). Un * al final acepta cualquier terminación: presupuest* = presupuesto, presupuestal, presupuestaria… Además, toda norma cuyo texto completo mencione a la ATU se incluye siempre. El número junto a cada término indica cuántas normas del historial lo contienen. Los cambios se aplican desde la siguiente revisión diaria.

¿Cómo obtengo el token de GitHub para guardar?
  1. Abra github.com/settings/personal-access-tokens/new (con su cuenta).
  2. Nombre: panel normas. Expiración: la que prefiera.
  3. Repository access: Only select repositories → monitor-normas-elperuano.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, cópielo y péguelo en el recuadro de abajo. Queda guardado solo en este navegador.
También puede editar el archivo directamente en GitHub.
